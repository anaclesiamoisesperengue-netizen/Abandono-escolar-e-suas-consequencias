# Educar é Transformar — Abandono Escolar

Website educativo criado para o trabalho escolar de Anaclesia (n.º 06) e Letícia Sérgio (n.º 28).

## Ficheiros
- `index.html` — conteúdo e estrutura do website.
- `style.css` — design responsivo para telemóveis e computadores.
- `script.js` — menu móvel e questionário interactivo.

## Como abrir
1. Extraia o ficheiro ZIP.
2. Abra a pasta `site_abandono_escolar`.
3. Clique duas vezes em `index.html` ou abra-o num navegador.

## Como publicar no GitHub Pages
1. Entre em https://github.com e crie um repositório público, por exemplo `abandono-escolar`.
2. Carregue `index.html`, `style.css`, `script.js` e a pasta `assets` (se existir) para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub mostrará o endereço do website na mesma página.

## Observações
- O website utiliza uma fonte do Google Fonts; sem Internet, o navegador usa fontes alternativas.
- Os links de referência abrem páginas de instituições como UNICEF e UNESCO.
- Os dados estatísticos estão contextualizados com a fonte e o período de recolha. Não representam uma estimativa actual de todos os alunos.
- Antes da entrega, confirme se o professor exige nome da escola, turma, disciplina, docente ou data; esses dados podem ser acrescentados na secção do grupo.
